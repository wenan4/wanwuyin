# 万物有声 · 项目方案 v0.1

> 群核 Aholo 3D AI 黑客松 · 2026-10-31 草案

## 0. 一句话

**Lux3D 给了物体外观，我们给它一副会振动的身体。**

AI 生成的 3D 物体都是空壳：看着像瓷，敲起来没声音，拿起来没重量，打印出来摸着全是塑料。万物有声把 Lux3D 生成的 PBR 材质翻译成物理参数，让每件生成物体在 3D 空间里**看得见地振动、听得见地发声、掂得出重量**，再把这副"身体"送到视障者的手里和耳朵里。

## 1. 核心命题：主角是 3D，声音只是振动的一个出口

我们真正计算的是**物体的 3D 振动形态（模态）**。同一组振型同时驱动四种输出：

| 输出 | 用户看到 / 感到 | 3D 在其中的角色 |
|---|---|---|
| 形变 | 一敲，杯子像果冻一样慢动作晃动（高速摄影效果） | 振型直接驱动顶点位移 |
| 沙纹 | 撒在盘、钟、锣上的沙子跳动着聚成克拉尼图案 | 沙粒沿 3D 表面移向节线 |
| 声音 | 叮、笃、嗡 | 振型在敲击点的分量决定音色 |
| 重量 | 铁锅砸下去很沉，泡沫球轻飘飘 | 体积 × 密度 → 刚体质量 |

所以演示里的每一帧都先是一个**在动的 3D 物体**，声音是伴随结果。让 3D 当主角的五个设计：

1. **每次敲击都有可见形变**：慢放 200–1000 倍、振幅夸张，表面叠加振动热力图
2. **振型图谱**：每件物体的前 6–12 阶振型做成 3D 动画卡片，相当于它的"物理身份证"
3. **克拉尼沙纹**：在 3D 曲面上实时生成（盘、钟、锣这类朝上的表面效果最好）
4. **调音就是在 3D 里改尺寸**：编钟架上的物体一个比一个大，尺寸就是音阶
5. **3D 空间决定混响**：同一个钟放进 SpatialGen 生成的石头教堂、竹林、洞穴，声音各不相同

## 2. 体验设计

### 模式一「叩物」沙盒（P0）

流程：输入一句话或拍一张照 → 等待"铸造中"（Lux3D 生成，等待动画做成浇铸 / 烧制）→ 物体落到台面上。

| 操作 | 效果 |
|---|---|
| 点击 = 敲击 | 敲不同位置，形变和声音都不同（刀柄 vs 刀身） |
| 拖动 = 刮擦（P1） | 纹理声：光滑的瓷 vs 粗糙的石 |
| 甩出去 = 掉落（P1） | 物理碰撞 + 碰撞声，重的东西砸得更狠 |
| 材质 X 光 | 部件按推断出的材质着色，显示密度、刚度 |
| 换材质 | 调用 Lux3D 材质重绘：瓷杯 → 青铜杯，外观、重量、晃法、音色一起变 |

### 模式二「编钟工坊」（P0 简版）

- 用户放进任意 N 件物体（鸭子、铁锅、石头……），选一个音阶或一首曲子
- 每件物体求缩放比 `s = f_当前 / f_目标`，让基频落在目标音上，物体在 3D 里长大或缩小；缩放过于极端（s > 3 或 < 0.3）时自动换八度
- 自动排上编钟架，用户可以按 MIDI 播放，也可以点击演奏
- 产出一段"7 件 AI 物体演奏《茉莉花》"的视频，作为传播主力

### 模式三「听触」视障子方向（P0 核心 + P1 扩展）

见第 4 节。

### 模式四「听音造物」挑战（P2，有余力再做）

给一段目标声音，玩家描述或重绘物体去逼近它，按频谱相似度打分。

## 3. 技术方案

### 3.1 总体架构

```
 文本 / 图片 ──▶ Lux3D 文生 / 图生 (G1, G1-Turbo) ──▶ GLB + PBR 贴图
                        │ 部件拆分 / 材质重绘
                        ▼
 [材质推断] 多视角渲染 + metallic / roughness 统计 ──▶ VLM 分类 ──▶ ρ, E, ν, 阻尼
                        ▼
 [网格预处理] 减面 → 薄壁加厚 → 实体体素化 (48³–64³)
                        ▼
 [模态分析] 体素有限元 K, M → 广义特征值 → 前 40 阶频率 + 振型 ──▶ modes.bin
                        ▼
 ┌──────────────── Web 前端（实时）────────────────┐
 │ 渲染：振型驱动顶点着色器（形变 / 热力图 / 沙纹）  │
 │ 音频：AudioWorklet 模态合成（敲击 / 刮擦 / 碰撞）│
 │ 物理：Rapier 刚体，质量 = 体积 × ρ               │
 │ 舞台：SpatialGen 3DGS 世界 + 卷积混响            │
 └────────────────────────────────────────────────┘
                        ▼
 [听触打印] 缩放到掌心 → 可打印性修复 → 盲文压印 → STL
```

### 3.2 材质推断

> **当前实现（2026-10-31）**：`wwys/material_id.py` 做自动初判，`scripts/material_review.py` 做视觉复核。
> - 三个来源的可信度，从高到低：重绘意图（参考图是什么材质就标什么）> 复核结论（`material.json`）> 自动规则。
> - 自动规则：逐面采样 Lux3D 的颜色贴图和金属度 / 粗糙度贴图，按规则打分，加上提示词关键词先验，在相邻面之间平滑后得到材质区域。
> - 实测：调参用的 4 件（瓷碗、青铜甬钟、玄武岩石臼、木雕）整件判对，但区域层面仍有误判；Lux3D 的金属度通道不可靠（木雕估成 0.43，重绘的铜碗只有 0.03），所以复核这一步保留。
> - 下面的 VLM 方案是复核环节的自动化替代，拿到魔搭 token 后接到同一个接口上。

- 输入：每个部件的多视角渲染图，加上该部件 metallic / roughness 贴图的统计量
- 用 VLM（魔搭 API 的 Qwen-VL 系列，可用免费魔粒值）在固定类别中选一个：钢、青铜、铝、铸铁、玻璃、瓷、陶、石、木、竹、硬塑料、橡胶
- 物理参数初值（文献常用值，最终按听感校准）：

| 材质 | 密度 ρ (kg/m³) | 杨氏模量 E (GPa) | 泊松比 ν | 阻尼 |
|---|---|---|---|---|
| 钢 | ≈7850 | ≈200 | 0.29 | 很低 |
| 青铜 | ≈8800 | ≈110 | 0.34 | 很低 |
| 铝 | ≈2700 | ≈70 | 0.33 | 低 |
| 玻璃 | ≈2500 | ≈70 | 0.22 | 低 |
| 瓷 | ≈2400 | ≈70–100 | 0.2 | 低 |
| 石（花岗岩） | ≈2700 | ≈50 | 0.25 | 中 |
| 木 | ≈600–750 | ≈10（顺纹） | 0.3 | 高 |
| 硬塑料 / PLA | ≈1050–1250 | ≈2–3.5 | 0.35 | 高 |
| 橡胶 | ≈1100 | ≈0.01–0.1 | 0.49 | 极高 |

- 阻尼用 Rayleigh 模型（α + βω²），初值参考 NeuralSound 等论文的材质表；木材按各向同性近似
- 前端提供纠错入口：识别错了用户可以改，X 光模式让错误一眼可见

### 3.3 模态分析（离线，每个形状只算一次）

1. Lux3D 网格常有不封闭、薄壁的问题：先减面到约 2 万面，薄于 2 个体素的部分沿法向加厚，再做实体体素化（flood fill 填充内部）
2. 每个体素是一个 8 节点六面体单元，组装稀疏刚度矩阵 K 和质量矩阵 M
3. 用 `scipy.sparse.linalg.eigsh` 的 shift-invert 模式求最小约 46 个特征值，去掉 6 个刚体模态，留 40 阶
4. 频率 `f_i = √λ_i / 2π`，衰减率 `d_i = (α + β·ω_i²) / 2`；超出 20 kHz 的阶直接丢弃
5. 振型从体素节点三线性插值到表面顶点，按 fp16 存储
6. 预期耗时：48³ 网格单件几秒到一分钟，和 Lux3D 生成一起排队

**两条省算力的物理规律（同时也是产品卖点）：**

- **同形同材，尺寸放大 s 倍 → 所有频率变为 1/s。** 编钟工坊靠它调音，不用重算。
- **只换材质（ν 相近）→ 振型不变，频率乘 `√((E'/ρ') / (E/ρ))`，阻尼换成新材质的值。** 材质重绘后音色可以瞬间切换，不用重算。

**多材质物体**（比如木柄铁锅）：部件拆分后逐部件赋材质，体素带材质 ID 组装出非均质的 K / M。这种情况下改单个部件的材质需要重算，放在后台跑即可。

### 3.4 实时合成与渲染

- **敲击**：射线拾取敲击点 v 和法线 n，第 i 阶激励 `a_i ∝ (φ_i(v)·n) × 冲量`；声音 `= Σ a_i · e^(−d_i·t) · sin(2π·f_i·t)`，在 AudioWorklet 里实时合成
  - 接触时长：硬锤接触时间短，能激发高阶，声音更亮；软锤更闷。用半正弦力脉冲的频谱给 a_i 加权
  - 叠加 5–10 ms 的接触噪声瞬态和混响，真实感会明显提升
  - 声辐射（acoustic transfer）先用简化权重，有余力再参考 NeuralSound
- **形变**：顶点着色器 `u(v,t) = Σ a_i · e^(−d_i·t') · sin(2π·f_i·t'/k) · φ_i(v)`，k ≈ 200–1000 控制慢放，振幅做夸张，同时按 |u| 叠加热力图
- **克拉尼沙纹**：持续驱动第 j 阶，在表面撒上千个沙粒；每帧的随机抖动幅度正比于 |φ_j|，振得厉害的地方沙子被弹开，最后停在节线上
- **刮擦**（P1）：手指沿表面移动 → 沿 UV 路径采样 normal / roughness 贴图 → 得到激励信号 → 送进同一组模态滤波器（参考 FoleyAutomatic, SIGGRAPH 2001）
- **碰撞**（P1）：Rapier（WASM）刚体，碰撞体用 CoACD 做凸分解；质量 = 体素体积 × ρ；碰撞冲量直接触发敲击合成
- **舞台与混响**（P1）：SpatialGen 生成 3DGS 世界作舞台；房间体积 V 取包围盒（或用 SpatialLM 布局），按 Sabine 公式 `RT60 = 0.161·V / A` 生成合成冲激响应做卷积混响，体现"空间决定声音"

### 3.5 渲染栈（Day 1 需验证）

- 首选 Aholo Viewer（`@manycore/aholo-viewer`），同时渲染 3DGS 舞台和网格物体，技术栈分更高
- 需要验证：它的 Drawable 是否支持自定义顶点着色器，或者每帧更新顶点
- 不支持的话：网格层用 Three.js，3DGS 舞台单独渲染再合成，或者把舞台降级为静态背景

### 3.6 Lux3D 用在哪（对应 30% 的技术栈分）

| Lux3D 能力 | 在作品中的作用 | 缺了它会怎样 |
|---|---|---|
| 文生 / 图生 3D（G1, G1-Turbo） | 所有可交互物体的来源：现场用 Turbo，展示库用 G1 | 无物可敲 |
| PBR 材质（金属度、粗糙度、法线） | 材质推断的输入，也是刮擦纹理声的来源 | 推不出物理参数 |
| 部件拆分 | 逐部件赋材质、逐部件发声、逐部件压盲文编号 | 一件物体只有一种声音 |
| 材质重绘 | 换外观 = 换音色 + 换重量 + 换晃法 | 核心玩法消失 |
| 多格式导出 | 听触打印（STL / OBJ） | 没法打印 |

给评委的一句话：**Lux3D 的材质越准，声音就越真**。材质质量被直接变成了可听、可量化的输出。

其他群核工具：SpatialGen（舞台）、Aholo Viewer（渲染）、Aholo Reality（可选，扫描真实物体或房间做对比）、SpatialLM（可选，用房间布局算混响）。

## 4. 子方向「听触」：在摸不到的地方替代触觉，在摸得到的地方补全材质

> 内容供给线"课本插图 → 触摸件"单独成文：[子方向-课本插图转触摸件.md](子方向-课本插图转触摸件.md)

### 4.1 为什么它和主线是一体的

- 视障者本来就在用耳朵"摸"材质：盲杖敲地，听的就是脚下是砖、铁板还是木板
- 3D 打印触摸模型只能还原**形状**，打出来的瓷碗、铜钟、石狮子摸起来都是塑料
- 万物有声正好补上**材质**和**真实尺度**：手负责形状，耳朵负责材质和大小
- 触摸做不到的三种情况，由声音来替代：
  - **太大**：两米高的钟、石狮子。手里是 10 cm 的打印件，耳朵里是按 2 米真实尺寸算出的钟声
  - **太脆或太贵**：瓷器、玻璃柜里的东西
  - **不存在或太远**：课本插图、想象中的东西
- 能直接对上八年级物理"声现象"一章：音调由大小决定，音色由材质决定，视障学生可以亲耳验证

### 4.2 产品形态

**A. 语音优先的入口**

- 说"我想认识编钟"，或老师拍一张课本插图 → Lux3D 生成 → 部件拆分 + VLM 给部件命名 + 估计真实尺寸（可人工修改）
- 全程可以用读屏软件操作，所有按钮都有语音标签

**B. 自动生成触摸打印件（3D 几何处理的重头戏）**

1. 缩放到掌心尺寸（10–15 cm），并记录缩放比
2. 可打印性修复：薄于 2 mm 的部分加厚，悬浮的小件合并或删除，补洞
3. 加平底座，底座侧面压印盲文名称
4. 每个部件在最平坦（曲率最低）的区域自动压印一个盲文编号，盲文点沿表面法线凸起
5. 底座预留 NFC 贴纸槽（P2）：手机碰一碰就打开这件物体的听触页

- 盲文采用《国家通用盲文方案》。点径约 1.5 mm、点高约 0.5 mm、点距约 2.5 mm，以国标为准，首批打印必须请视障者试摸
- FDM 打印盲文效果一般，有条件就用光固化
- 中文转盲文可以试 liblouis 的中文表（需确认是否覆盖国家通用盲文）；不行就先只压数字编号，名称改用语音播报

**C. 听触 App（不打印也能用）**

| 功能 | 做法 |
|---|---|
| 按编号听 | 摸到打印件上的盲文"3" → 说"3"或按数字键 → 听到"这是钮，青铜做的"，外加按真实尺寸合成的敲击声 |
| 敲 | 在屏幕上的物体任意位置点一下，播放该点的材质声 |
| 滑 | 手指在物体上慢慢滑过，播放纹理声 |
| 摸屏探索（P1） | 手指移动时，持续音的音高表示深度（越近越高）；越过轮廓发出"咔"声；进入新部件时读出部件名 |
| 大小对比 | 同一件物体按 10 cm、1 m、3 m 各敲一次，用耳朵理解尺度 |

注意事项：

- iOS Safari 不支持网页振动 API，触感反馈只在安卓上有效，iOS 只能靠声音
- 读屏软件（VoiceOver / TalkBack）会拦截触摸手势：探索画布要专门测"直接触控"，测不通就提示用户暂时关闭读屏
- 措辞用"补全触觉"，不说"代替视力"，也不做医疗或辅具方面的承诺

### 4.3 必须有真实用户

- 第一周就联系本地盲校、盲协或小红书上的视障博主，约 2–3 位视障测试者，每人 30 分钟
- 测三件事：盲文能否摸清楚；听材质能否答对（瓷 / 木 / 铁三选一盲测）；听声音能否给尺寸排序
- 征得同意后录像，作为视频高潮和功德无量奖的证据
- 实在约不到，就用蒙眼的明眼人测试，并在提交材料里如实说明

## 5. 杀手级演示：sim2real（仿真对上现实）

- **方案 A（不用打印机，最便宜）**：拍一张家里真实的碗 → Lux3D 图生 3D → 量真实口径确定尺寸 → 预测声音 → 真敲一下录音 → 两条频谱叠在一起对比
- **方案 B（打印）**：先打印一根 PLA 长条，标定出打印件的等效模量（FDM 打印有各向异性，比手册值偏软），再用标定值预测打印小钟的频率，最后实测对比
- 预测和实测的前几个峰能对上，就是技术学霸奖最硬的证据；对不上也要如实给出误差

- **新物种奖的讲法**：生成式 3D 资产多了一个新属性。每件资产附带一个 modes 文件（频率、阻尼、振型），可以提一个 glTF 扩展草案（名字自拟，比如 `EXT_modal_sound`），任何引擎拿到都能让它响。
- **VC 奖的讲法**：游戏和影视的自动拟音；电商里"听听这个碗是不是真瓷"；视障教育教具。

## 10. 风险与预案

| 风险 | 预案 |
|---|---|
| FEM 太慢或网格太脏 | 降到 48³；离线预计算；最后的退路是"材质模板 + 尺寸缩放"（效果约七成） |
| 材质识别错 | 用户可修改；X 光模式让错误可见 |
| 声音听着假 | 加接触噪声瞬态和混响；演示优先选会"响"的物体（钟、碗、杯、金属条），少用软物 |
| Aholo Viewer 不支持自定义着色器 | 网格层改用 Three.js，3DGS 舞台单独渲染 |
| Lux3D 排队慢、额度紧 | 预生成素材库；现场只用 G1-Turbo；把等待做成"铸造中"动画 |
| 盲文打印不清 | 用光固化或放大点径；先打样试摸 |
| 约不到视障测试者 | 改做蒙眼测试，并如实说明 |

## 11. 90 秒视频脚本

| 时间 | 画面 |
|---|---|
| 0–5s | AI 生成的瓷杯被敲一下，慢动作里像果冻一样晃，"叮"。字幕：AI 生成的杯子，第一次发出了声音 |
| 5–20s | 材质重绘：瓷 → 青铜 → 木，外观、晃法、声音一起变 |
| 20–35s | 沙子在生成的铜盘、铜钟上跳成克拉尼图案 |
| 35–55s | 鸭子、铁锅、石头……7 件物体自动缩放排成编钟，在石头教堂里演奏《茉莉花》 |
| 55–80s | 视障测试者摸着 10 cm 的打印钟，手机里传出 2 米大钟的声音；接一句测试者的原话 |
| 80–90s | 真碗与预测声音的频谱叠图。Slogan：Lux3D 给了物体外观，我们给它一副会振动的身体 |
